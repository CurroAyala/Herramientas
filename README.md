# 💻 Apuntes de herramientas de consola, DevOps y administración de sistemas.

Repositorio personal con apuntes, chuletas (*cheatsheets*) y ejemplos.

---

## 📂 Contenido

### 🖥️ Consola
* [CMD](consola/comandos_cmd.txt) – Comandos básicos y administración en el Símbolo del sistema de Windows.
* [Linux](consola/comandos_linux.txt) – Comandos esenciales de Bash/sh, gestión de paquetes, permisos y utilidades del sistema.

### ⚙️ DevOps
* [Docker](devops/comandos_docker.txt) – Gestión de contenedores, imágenes, volúmenes y Docker Compose.
* [Git](devops/comandos_git.txt) – Flujos de trabajo, ramas, resolución de conflictos y comandos habituales.
* [GitLab CI/CD](devops/gitlab_cicd.txt) - Creación de pipelines para GitLab.

### 🌐 Redes
* [Nmap](redes/comandos_nmap.txt) – Escaneo de puertos, descubrimiento de hosts y detección de servicios.
* [Nslookup](redes/comandos_nslookup.txt) – Consultas DNS y resolución de nombres.

### 🔒 Seguridad
* [ClamAV](seguridad/comandos_clamav.txt) – Escaneo antivirus desde la terminal y actualización de firmas.
* [Metasploit](seguridad/comandos_metasploit.txt) – Uso básico de `msfconsole` y búsqueda y personalización de módulos.

### 📦 Virtualización
* [Vagrant](virtualizacion/comandos_vagrant.txt) – Automatización y gestión de máquinas virtuales.
